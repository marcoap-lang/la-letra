# La Letra

Mostrador de **Imprenta La Letra S.A. de C.V.**, avenida 5 de Mayo 357, centro de Tuxtepec, Oaxaca.

Sirve para anotar trabajos del taller y del mostrador: sellos, talonarios, invitaciones, papelería, copias, lonas y lo que se le agregue. Lleva abonos, saldos, fecha y un mensaje listo para WhatsApp.

En el inicio se ve dónde está cada cosa: **Pendientes**, **Listos**, **Por cobrar** y **Papelería**. También se puede buscar por cliente, trabajo o número.

Los datos se quedan en ese aparato. Desde el inicio se puede **guardar una copia** y **traerla** de vuelta si se cambia de equipo.
